How a curve is drawn

Read the method →

(a)Lat/lon → x, y, z

Each coordinate is projected onto a sphere of radius r = 20.

(b)Lift the control point

The midpoint is pushed outward so the arc clears the surface.

(c)Sweep a tube

A TubeGeometry follows the curve so it reads at any zoom.

Interaction

OrbitControls for drag and zoom; press H to hide the panel, D to draw.
